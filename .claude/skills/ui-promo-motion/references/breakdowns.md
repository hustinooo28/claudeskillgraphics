# Reference breakdowns

## B — Motivational kinetic reel (9:16, 14.6 s) · @rehmaneditor999

Structure: **claim → object metaphor → truth → contrast (hard work) → social proof (phone) → call to stop/start.** Monochrome with grey type.

| t | Shot | What moves | Out |
|---|---|---|---|
| 0.0–1.5 | Off-white; giant blurred black asterisk blobs at the edges, slowly rotating (T13) | Arrow cursor sweeps in; "Everyone is chasing SHORTCUTS" types in as the cursor drags out a dashed selection box with handles (T11) | text smears sideways |

## D — Productivity-app teaser (16:9, 20 s) · @thednyx / dnyxstudios

Structure: **"These days…" → everywhere (map) → tool chain on a line → website cloud → "progress slows" → "clarity disappears" (dark) → phone + app cloud → cards → "Work together" → logo "Work. Organised." → studio card.**

| t | Shot | What moves | Out |
|---|---|---|---|
| 0.0–0.9 | Soft grey blobs. "These days" | Words fade and blur in | a map pin grows |
| 0.9–2.4 | City map; "Everywhere" huge with a dark text shadow | Map zooms in slowly; word scales up | blur |
| 2.4–5.0 | Grey canvas. Notes icon → blue line → Reminders icon → line → Pages icon | Icon pops, then the line draws to the next icon while the camera follows (T16); each hop ~0.8 s | burst |
| 5.0–6.5 | Pages icon centred; website cards burst out around it (T12) | Cards drift outward | cards exit off-frame |
| 6.6–9.0 | "So, progress **slows**" (accent blue) | Words in (T1); kinetic push ×2 (T5), slow drift, zoom-out with blur | **hard cut** |
| 9.2–9.9 | Black, scanlines. "clarity disappears" | Glitch text (T7) | cut |
| 10.0–13.3 | White. Phone rising, tilted in 3D; app icons (Docs, Excel, Teams, Meet) orbit it | Phone rotates; icons fly around it with blur | slide |
| 13.4–16.3 | Pastel task cards (red/blue/green) stack: "Marketing Meeting", "Campaign Ideas", "Content Ideas"; then "Work together" | Cards slide in from the left one by one, then the stack shrinks while a title appears above | fade |
| 16.3–18.8 | Notion-style logo + "Work. Organised." | Logo pops; words type and fade in beside it | hard cut |
| 19.0–20.2 | Black. "dnyxstudios" with a soft white glow | Glow blooms, then settles | end |

Takeaways: a connector line is a strong way to string features together. Keep one accent colour per shot. The dark glitch beat comes exactly at the "problem" line.
